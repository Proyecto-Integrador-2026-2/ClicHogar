## What I do

- List Azure DevOps projects and repositories
- Inspect work items and pull requests
- Check CI/CD pipeline statuses

## Configuration

Requires `AZURE_DEVOPS_PAT` and `AZURE_DEVOPS_ORG` environment variables.
